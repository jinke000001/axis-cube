# 教学手 v2 说明（只做到阶段 B）

分支 `codex/human-hand-v2`，从标签 `axis-web-cfop-54-2026-11-03-r2`（`e6f0ca8`）拉出。这一支上的规格、模型、三条样例动作和本说明是同一版。没有合并到 main，也没有重新发布。

## 手型

- 规格：`art/teaching-hand/rig.json`
- 编号：`axis-teaching-hand-v2`
- 几何摘要：`094a6cebd1aa23ffd5bfe09245e98b7555ff965813e5460d8794a4dfc377d29b`
- 运行时读取：`src/demonstrator/hand-model.ts`
- 模型：`public/models/teaching-hand/axis-teaching-hand.glb`（由 `scripts/build-teaching-hand.mjs` 按同一份规格生成）

骨长、指根位置、指腹半径、关节壳和手臂壳只写在这一份规格里。摆姿势、碰撞和建模都读它，不再各写一套尺寸。碰撞外壳按现在的暖白硬壳计算，不沿用旧的细手指尺寸。

骨头在动作里不拉长。够不到时记成到达误差，不把指节撑长。规格里写了关节角度上限，求解器目前还没有按这个上限夹紧。

外观是分段机械手：暖白硬壳、黑关节、金属连接环，掌心连到手腕，拇指单独朝向，五指长度和间距不同。手掌仍是圆角方壳，不是参考照片里那种雕刻掌面。只吸收了 PR #1 的暖白和圆角作为颜色参考，没有把 PR #1 的网格和旧碰撞配在一起。

公式的转面没有改。指定手指、分组、承托和接力的意图也留着。按新手重新算的是掌位、关节轨迹、指腹接触和手臂。

动作文件写入 `handModelId` 和 `geometryDigest`。加载和缓存键都会核对。对不上就停播，提示「本条动作资料未能加载」，不会拿旧轨迹去驱动这只新手。

119 个情形、121 条公式，以及其余 51 条已发布动作文件都没改。那 51 条仍是旧手型轨迹，打开后会拒绝播放。发布清单没有改；F2L 40 和 OLL 18 的清单校验和因此和文件不一致，要等以后的发布阶段再处理。

另外有 5 条公式现在编不过，这次不修，留给阶段 C：

- `gan-oll-01`、`gan-oll-53`、`gan-pll-15`：接力让位需要未接触的闲指与接近指
- `gan-pll-06`：单拨掌空间标注必须匹配原步骤的真实驱动角色
- `gan-pll-16`：折形接收必须发生在手指离面期间

## PLL 16

基线 `e6f0ca8` 上，`gan-pll-16` 能编出来，但第 2 个边界起左手中指的 `resting` 是 false。这是原来的闲置停放：中指先沿掌前展开，给后面食指接收留通道（`authored-grips.ts`）。测试却期望它是 true。这和换手模型无关，所以没有改测试，也没有改这段停放。

上面那条「折形接收必须发生在手指离面期间」是这只新手新出现的编译失败，和基线上的 `resting` 断言不是同一件事。三条样例不依赖它。当前那组时间线测试会更早停在 F2L 01 的 45 毫米净空上，vitest 报出来的不是 PLL 16 那一行。

## 检查

- `npm run build`：通过（2026-11-03，只有打包体积警告）。
- `npx vitest run`：16 失败，1182 通过，共 1198。断言没有放宽。

失败留在原处：

- 手臂：F2L 40 肘部往返差 0.000058 米，阈值是 0.00002 米。PLL 12 腕点超出固定骨长，这条没有重算。
- 碰撞：旧的「手腕偏 4 厘米」合成姿势现在只偏 0.0085 米；一条食指穿掌合成姿势多出 0.00038 米；「前臂穿过手掌」的合成姿势不再被报出。历史 OLL 31 短碰撞仍钉在冻结的基线规格 `src/demonstrator/audit-fixtures/baseline-rig.json`（SHA256 `7016d209168d907ad6dd785f9e395d3aa5e795b40197ab6b50707769e87c3ac4`），该条通过。
- 时间线：多条测试在遍历全部公式时碰到上面的接力编译错误。其余实测差是 F2L 01 指根净空 0.0446 / 0.0449 米（阈值 0.045）、接触滑移 0.0008 米（阈值 1e-7）、卸力回掌 0.01258 米（期望 0.012）、支撑掌位约 0.002 毫米的深比较。
